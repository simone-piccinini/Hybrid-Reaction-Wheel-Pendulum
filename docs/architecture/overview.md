# Project Overview

## Goal

Design and optimize an inverted wheeled pendulum stabilization system using:
- LQR control
- Kalman state estimation
- Bayesian optimization

## System Objectives

- Stabilize upright equilibrium
- Minimize entropy and oscillations
- Minimize control effort
- Achieve robustness to disturbances

## Main Components

- Dynamics
- Estimation
- Control
- Optimization
- Simulation
- Metrics

## Development Philosophy

- Reproducibility first
- Modular architecture
- Deterministic experiments
- Strong mathematical consistency
