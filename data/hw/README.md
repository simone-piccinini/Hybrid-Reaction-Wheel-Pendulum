# Raw hardware logs

Serial captures from the bring-up firmware, exactly as they came off the board.

**These are version controlled on purpose.** Everything under `results/` is
gitignored because it can be regenerated by re-running a script. These cannot:
they are measurements of a physical machine at a moment in time, and if the
magnet shifts or a part is replaced they can never be reproduced. They are the
evidence behind every measured number in
[`docs/hardware/sensor_characterisation.md`](../../docs/hardware/sensor_characterisation.md).

## Naming

```
<stage>_<test>_<what>.log
```

e.g. `s0c_wobble_0deg.log`, `s0c_wobble_180deg.log`, `s1_freeswing.log`.

Keep the whole PuTTY session in one file — the analysers skip anything starting
with `#` and read the `#BEGIN` / `#END` blocks, so banners, idle lines and
several captures in one log all parse fine.

## Reading them

```bash
python scripts/analyze_wobble.py data/hw/s0c_wobble_180deg.log
python scripts/identify_parameters.py data/hw/
```
